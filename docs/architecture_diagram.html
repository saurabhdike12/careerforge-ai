🔄 End-to-End Request Flow — "Submit Answer" Example
1
User types answer in React frontend and clicks "Submit Answer"
2
FastAPI POST /session/{id}/answer receives the request, validates with Pydantic schema
3
Interview Agent calls the RAG pipeline's `evaluate_answer()` method with job role + experience context
4
LangChain RetrievalQA performs MMR search against ChromaDB — retrieves top 5 relevant interview evaluation documents
5
IBM Slate embeddings compute semantic similarity for retrieval; custom prompt template injects the context + question + answer
6
IBM Granite-13b-chat-v2 on watsonx.ai generates structured evaluation: scores, strengths, improvements, model answer, keywords
7
Answer Scorer parses Granite's output using regex → builds `AnswerFeedback` Pydantic model with `ScoreBreakdown`
8
Progress saved to SQLite; response returned to frontend → FeedbackPanel renders scores, strengths, improvements
